Иерархия состоит из трёх уровней: страна → штат → город.
Корневой узел — Бразилия (BR). К нему относятся штаты ST:PE. Для каждого штата выбирается до 20 городов с наибольшим количеством клиентов.

Пример path

Прямой путь от штата к городу:
штат PE -> город в PE

Обратный путь от города к стране:
город в PE -> штат PE -> BR

path хранит последовательность идентификаторов пройденных узлов.

Базовая часть выбирает начальный узел ST:PE, устанавливает глубину = 0 и записывает его идентификатор в path.
Рекурсивная часть находит дочерние узлы по условию parent_id = node_id предыдущего уровня. Для каждого найденного узла depth увеличивается на 1, а path дополняется его идентификатором.
Рекурсия завершается, когда новые узлы не находятся.
